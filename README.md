# EchoVRCE Switcher

One-click tool to point your Echo VR game at a community server, pick a game
mode, and switch it all back.

## Download

**Easiest:** [EchoVRCE-Switcher-Setup.exe](https://github.com/Decay-echo/echovrce-switcher/releases/download/v1/EchoVRCE-Switcher-Setup.exe)
-- open it (if Windows says "Windows protected your PC", click **More info ->
Run anyway**). It installs the switcher to its own folder, puts an
**EchoVRCE Switcher** shortcut on your desktop and opens it. Run it again to
update.

**Or the zip:** [EchoVRCE-Switcher.zip](https://github.com/Decay-echo/echovrce-switcher/releases/download/v1/EchoVRCE-Switcher.zip)
-- extract it somewhere it can stay and run **Switch.bat**.

The server address is already filled in. Close Echo VR, pick a mode, click
**Connect**, then start Echo. **Back to EchoVRCE (official)** undoes it all.

## Game modes

Normal, Gravity, Super Speed, and the experimental Tiny, Strength, Stretch,
Blink and Spider-Man. A Tiny player shows at their size to anyone on Tiny,
Strength, Stretch, Blink or Spider-Man.

See [README-PLAYERS.txt](README-PLAYERS.txt) for what each mode does and its
buttons.
