EchoVRCE Switcher
=================

Points your Echo VR game at a community server, and switches it back.
Do the Connect step once.

YOU NEED
  - A working EchoVRCE Echo VR install (the one you already play on).
  - The server address, which the host gives you (ask in their Discord).
    It looks like  1.2.3.4:7350  or  somename.duckdns.org:7350.

HOW TO USE
  1. Close Echo VR if it's open.
  2. Double-click  Switch.bat
       (If Windows shows "Windows protected your PC", click More info -> Run anyway.)
  3. Paste the server address the host gave you into the box.
  4. Click  "Connect to this server".
       - First time, it asks for your Echo VR folder: pick the one that
         contains  bin\win10\echovr.exe  (not inside bin).
  5. Start Echo VR. First time, the game shows a LINK CODE. In the Discord
     server, type  /link-headset  and enter that code.
  6. Play.

GO BACK TO NORMAL
  - Open Switch.bat again and click  "Go Back (undo)". Restores your
    original settings exactly.

The address you paste is saved only on your PC (my-server.txt next to this
tool). This download contains no server address.
