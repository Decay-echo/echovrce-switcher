# EchoVRCE Switcher

One-click tool to point your Echo VR game at a community server, and switch it back.

## Download
Grab the latest **EchoVRCE-Switcher.zip** from the [Releases page](../../releases/latest),
extract it, and run **Switch.bat**. Click **Connect** to join the server, **Go Back** to undo.

See README-PLAYERS.txt inside the zip for full steps.
